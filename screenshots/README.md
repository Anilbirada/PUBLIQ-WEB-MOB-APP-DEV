# PUBLIQ Application Screenshots Gallery

This directory houses high-resolution interface captures and operational recordings across the PUBLIQ platform.

## Directory Structure

- **`dashboard/`**: High-level executive KPIs, Restaurant & Bar POS terminal, Kitchen Display (KDS), Table Floor Maps, Inventory Control, and 5% GST liability reports.
  - `executive_dashboard.jpg` — Real-time midnight navy executive overview with sales, covers, tax, and inventory health.
- **`web/`**: Customer-facing luxury dining portal, culinary storytelling, digital menu, reservations, and banquet booking.
  - `customer_experience.jpg` — Editorial dining showcase and Blossom Atrium ambiance.
- **`mobile/`**: Cryptographic QR code mobile ordering flows, real-time WebSocket order tracking, and PWA digital receipts.

## How to Add New Screenshots
1. Capture screenshots at standard 1920x1080 (Desktop/Dashboard) or 390x844 (Mobile).
2. Place the `.jpg` or `.webp` file in the corresponding subfolder.
3. Reference the file in `README.md` using relative paths: `![Caption](screenshots/category/filename.jpg)`.
